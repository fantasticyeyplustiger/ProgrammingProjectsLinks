# ProgrammingProjectsLinks
a collection of links to WTC programming projects for future students to use to get inspiration. Add Project Title and link along with a short description.  If your project does not README file for instructions on how to setup/run project, include that here.

**Show Case project Examples**-----------------------------------------------------------

Penguin Massacure Gaim - https://github.com/Charlie-Quin/penguinMassacureGaim
  - A time manipulation game with interesting physics, you can slow down or rewind time and are a penguin trying to escape the North Pole and the evil elves where you were enslaved.
  - to run the game you can clone and run using Intellij or other Java IDE.  (Game was made with LIBGDX)
    
PainOS - https://github.com/SmartKirb99/PainOS/
 - An Operating System made within the Godot Game Engine

Go Go Go - https://github.com/fantasticyeyplustiger/go-go-go
  - A rhythm game with a 6x6 grid for a player to dodge obstacles on. Contains three levels, but has a functioning level editor and save system. Made in Godot.

2D Car Game - https://github.com/fantasticyeyplustiger/car-game
  - A 2D sidescroller car game with a level and upgrades. Made in Godot.

Puzzle Game - https://github.com/ItsTony-1/puzzleGameAttempNo3
  - A 2D puzzle game based on changing your ability through shapeshifting. Made in Godot.

Marrow - https://github.com/protogenposting/Marrow/ , https://github.com/protogenposting/Marrow-Launcher/releases/latest
  - A very basic animation software coded in IntelliJ. Contains most of the essentials needed, but a little buggy.

**Other examples**------------------------------------------------------------------------

Godot Launcher - https://github.com/SmartKirb99/Godot-Launcher
- A Basic Launcher made via Java Swing to allow you to easily run all your Godot Versions that YOU download.

Multithreading - https://github.com/fantasticyeyplustiger/multithreading
- A basic project that showcases the use of multithreading in Java by calculating the amount of power different groups of generators makes (with another thousand fibonacci calls) in different threads each.
- Also contains a showcase of the single-threaded version built in so you can see the difference in calculation time. Coded in Java via IntelliJ.

Blackjack - https://github.com/fantasticyeyplustiger/deck-of-cards-api
- A basic representation of Blackjack in console. Coded in Java and uses an API to get card information.
